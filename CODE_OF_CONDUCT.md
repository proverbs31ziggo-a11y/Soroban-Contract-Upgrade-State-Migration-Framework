# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people, and help
newcomers. Harassment, insults, and personal attacks are not tolerated in issues, pull
requests, or any other project space.

## Reporting

If someone's behaviour makes you uncomfortable, report it privately to the maintainer
through their [GitHub profile](https://github.com/proverbs31ziggo-a11y), or through the
repository's [private reporting form](https://github.com/proverbs31ziggo-a11y/Soroban-Contract-Upgrade-State-Migration-Framework/security/advisories/new) if you prefer.
Reports are kept confidential.

Maintainers may remove comments, close issues, or block contributors who break these
rules, following the Contributor Covenant's enforcement guidelines.
